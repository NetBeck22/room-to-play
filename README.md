# Room To Play

BUILD THIS WEBSITE — ROOMS.

Create a highly experimental, art-directed, interactive website for a future contemporary art gallery called ROOMS.

This is NOT a normal gallery website.

This is NOT a clean luxury art website.

This is NOT a 3D virtual gallery.

This is NOT a generic Awwwards landing page with gradients, floating blobs and WebGL.

The website itself must feel like an interactive contemporary artwork / artist book / strange digital world.

The user should feel like they accidentally opened a beautiful, weird, hand-crafted art object on the internet.

The experience should be playful, editorial, tactile, slightly absurd, sophisticated and highly visual.

02 — WHAT I LIKE ABOUT THE REFERENCES

TIAGO FRAGOSO

This is one of the most important references.

The website feels like somebody physically drew their portfolio.

There are:

hand-drawn frames

hand-drawn typography

illustrated walls

imperfect lines

strange little visual jokes

doodles

objects

annotations

visual storytelling

a feeling that the whole page is one giant illustration

The website is effectively a hand-drawn physical world.

I want to borrow this principle.

But instead of a portfolio wall, our world is an art gallery / artist book.

The website should feel as though someone drew the architecture of the gallery on paper and then made the drawing interactive.

IMPORTANT:

Do not make the doodles childish.

Think:

ARTIST SKETCHBOOK
+
ARCHITECT'S DRAWING
+
EDITORIAL ILLUSTRATION
+
CONTEMPORARY ART

NOT:

children's website
NOT:
random hand-drawn stickers.

03 — NICCOLÒ MIRANDA

Use Miranda as the main interaction reference.

Important characteristics:

horizontal exploration

unconventional navigation

typography becoming part of the composition

large type

words split apart

letters moving independently

image transitions

cursor interactions

"drag sideways" instructions

unexpected navigation

website behaving like an interactive artwork

strong art direction

motion that has purpose

The website should not feel like:

"Here is a section. Scroll down."

Instead it should feel like:

"What happens if I move this?"

"What is that object?"

"Why is that word moving?"

"Can I enter that?"

The user should discover the navigation.

04 — PEAR

Use Pear as a reference for:

oversized typography

unexpected text positioning

text broken across the screen

chapters

scroll-driven storytelling

typography as an architectural element

However:

Do NOT make ROOMS look like a software agency.

It is an ART GALLERY.

So take the visual grammar, not the branding.

05 — JULIEN CALOT

Use this as reference for:

treating art as a collection

strong artwork imagery

artwork titles

artist identity

collections/chapters

letting the artwork dominate

unconventional but simple presentation

The artworks should feel like objects worth discovering, not webshop products.

06 — THE CORE CONCEPT

The gallery is called:

ROOMS.

Possible tagline:

ART, BUT MAKE IT A PLACE.

or:

COME IN. LOOK AROUND.

or simply:

CONTEMPORARY ART / LEUVEN

The fundamental concept:

Every artwork changes the space around it.

Therefore the website is a collection of spaces.

But these spaces are not realistic 3D rooms.

They are illustrated, collaged, animated digital spaces.

Imagine:

a physical artist book

that has been drawn by hand

then photographed

then turned into an interactive website.

07 — VISUAL CONCEPT

Imagine opening a large art book.

The first page is almost empty.

There is a tiny hand-drawn floor plan.

A little arrow says:

→ COME IN

You click it.

The paper shifts.

The page becomes a room.

The room is a combination of:

hand-drawn architecture

scanned paper

real artwork photography

imperfect shadows

cut-out objects

typography

little annotations

animated drawings

The artwork is real.

The world around it is illustrated.

This distinction is VERY important.

08 — DO NOT BUILD A NORMAL HERO

Do not start with:

"ROOMS."

centered on a black background

with a giant 3D animation.

That is too generic.

Instead create a strange composition.

Example:

In the centre is a crude architectural drawing:

ROOM 01

There is a tiny hand-drawn door.

Beside it:

"you can come in"

A hand-drawn arrow points towards the door.

The cursor becomes a little hand.

When clicked:

the drawing opens.

12 — ARTWORK INTERACTION

This is extremely important.

The artwork should not simply have:

:hover { transform: scale(1.05); }

That is boring.

Instead:

When the cursor approaches the artwork:

The illustrated room subtly changes.

The shadow underneath the artwork moves.

A hand-drawn circle appears around it.

A small handwritten annotation appears:

"LOOK CLOSER"

When clicked:

the artwork detaches from the wall.

The rest of the room moves backwards.

The artwork comes forward.

The screen becomes an artwork detail page.

14 — TYPOGRAPHY

Typography is one of the main visual tools.

Use three layers:

1. Large editorial type

Huge sans-serif typography.

Examples:

ROOMS

LOOK

INSIDE

NEXT

ART

SPACE

Use very large sizes.

Sometimes letters should go beyond the viewport.

2. Elegant serif

Use a beautiful italic serif for emotional words.

Example:

ROOMS.

art becomes a place.

3. Tiny technical text

Use monospace.

Examples:

ROOM 01
LEUVEN / BELGIUM
160 × 110 CM
OIL ON CANVAS
CLICK TO ENTER

This creates the feeling of:

artist book
+
architecture
+
museum archive.

16 — HAND-DRAWN DETAILS

Create an SVG-based hand-drawn visual language.

Important:

Use imperfect lines.

Do not use generic icon libraries.

Create custom SVG drawings for:

arrows

doors

floor plans

chairs

plants

frames

little figures

stars

circles

measurement lines

room numbers

underlines

These should look like they were drawn with a black pen.

Some lines should be slightly crooked.

Some circles should not be perfectly circular.

17 — CURSOR

Desktop:

Create a custom cursor.

Normal state:

small imperfect circle.

Hovering an artwork:

cursor becomes:

LOOK

Hovering a door:

ENTER →

Hovering next:

NEXT →

Hovering an artist:

MEET →

The cursor should feel like part of the drawing.

Mobile:

disable the custom cursor.

18 — HORIZONTAL NAVIGATION

This is important.

At least one major section should move horizontally.

For example:

The user reaches:

CHAPTER II

and the website says:

← DRAG →

Then the user drags horizontally through:

ROOM 01
→
ROOM 02
→
ROOM 03
→
ARTISTS
→
COLLECTION

Do not simply put a horizontal scrollbar.

Make the movement feel intentional.

Use smooth inertia.

GSAP / Lenis can be used.

Works can be scattered across the page.

Use subtle textures:

25 — MOTION STYLE

Motion should feel:

physical
slightly imperfect
slow where necessary
responsive
playful
editorial

Avoid:

excessive parallax

generic fade-ins everywhere

spinning 3D objects

glowing gradients

excessive blur

startup-style animations

bouncing UI

glassmorphism

Every animation should have a reason.

26 — SMALL SURPRISES

Include small discoveries.

Examples:

A tiny person walking across a wall.

A hand-drawn arrow that moves when you hover it.

A chair that can be dragged slightly.

A handwritten note saying:

"don't look here"

which opens something.

A painting that changes the room lighting.

A door that appears only after scrolling.

A tiny mouse drawing hiding somewhere.

These moments should reward curiosity.

27 — HUMOUR

The website should have personality.

Not corporate.

Not pretentious.

Not overly serious.

Occasionally use small pieces of copy like:

"yes, you can touch it."

"look closer."

"we like this one."

"don't ask why."

"there's another room."

"you missed something."

"keep going."

This is important.

The gallery should feel curated by a real person.

29 — THE BUSINESS SHOULD STILL BE CLEAR

Despite being experimental, the user must eventually understand:

This is a contemporary art gallery.

The gallery discovers artists.

The gallery exhibits artworks.

The artworks are available for purchase.

The gallery can organise exhibitions in:

restaurants
hotels
shops
private spaces
temporary locations

Therefore eventually include:

ARTISTS

EXHIBITIONS

ABOUT
CONTACT

But integrate them into the experience.

30 — FUTURE PHYSICAL GALLERY

Maybe near the end:

LEUVEN

"one day, this will be a real room."

33 — MOST IMPORTANT DESIGN RULE

Before writing code, ask yourself:

"Could this website exist without the interaction?"

If the answer is yes, the design is not experimental enough.

The website should rely on:

movement
discovery
interaction
typography
illustration
spatial composition

The user should participate.

34 — FINAL CREATIVE DIRECTION

The final result should feel like:

an artist drew a contemporary art gallery on paper, photographed the pages, cut pieces of the paper apart, placed real artworks into the drawings, animated the pieces, and turned the whole thing into an interactive website.

It should feel somewhere between:

an artist's sketchbook
+
an architecture magazine
+
a contemporary art catalogue
+
a children's book for adults
+
an experimental Awwwards website.

But it must remain sophisticated.

The reference websites are inspiration for their creative courage, not templates.

The most important goal:

When someone visits ROOMS., they should not think:

"Nice gallery website."

They should think:

"WHAT THE HELL IS THIS? I WANT TO LOOK AROUND."

Build that.
